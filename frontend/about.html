脑肿瘤 MRI 图像识别

基于深度学习的多模态 MRI 影像分析平台，辅助临床快速完成脑肿瘤分类与分割。

项目简介

BTIR（Brain Tumor Image Recognition）是一个面向脑肿瘤 MRI 影像的智能识别平台。系统接收患者多模态 MRI 数据（T1、T1c、T2、FLAIR），自动完成肿瘤分类概率预测与三分区（WT、TC、ET）体积分割，并通过三维体素可视化呈现结果，为放射科医生提供辅助诊断参考。

平台支持 NIfTI、DICOM 文件夹及 ZIP 压缩包上传，提供任务管理与复查随访功能，可对同一病例的多次检查进行纵向对比，帮助跟踪病情变化。

核心功能

覆盖从影像上传到结果可视化的完整临床工作流

多模态上传

支持 NIfTI、DICOM 文件夹与 ZIP 包，拖拽即可提交 T1 / T1c / T2 / FLAIR 四模态数据。

肿瘤分类

深度学习模型输出肿瘤概率，辅助判断是否存在肿瘤及恶性程度。

三分区分割

自动分割整体肿瘤（WT）、肿瘤核心（TC）与增强肿瘤（ET），并给出体积。

三维可视化

基于 NiiVue 的体素渲染，多视图联动浏览，直观观察肿瘤空间分布。

任务管理

批量提交与跟踪识别任务，查看历史记录与处理状态，提升工作效率。

复查随访

对同一病例多次检查进行纵向对比，跟踪肿瘤体积与性状变化趋势。

技术架构

前后端分离架构，前端专注交互与可视化，后端承担推理与存储

前端 Vue 3 组件化开发，NiiVue 实现医学影像体素渲染，原生 CSS 变量主题系统支持深浅色切换。
后端 Python 服务端，提供影像上传、任务调度、模型推理与结果存储的 RESTful 接口。
模型 深度学习网络完成肿瘤分类与三分区分割，输出概率与逐体素标签。
数据 兼容 BraTS 系列数据格式，支持 NIfTI 与 DICOM 两种医学影像标准。
